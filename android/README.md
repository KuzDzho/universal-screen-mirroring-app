# Виста — Android приложение для дублирования экрана и звука на ТВ

Минималистичное приложение для Android смартфонов (Android 8.0 — Android 15), которое автоматически находит Smart TV любой марки в локальной сети Wi-Fi и дублирует на него экран со звуком в одно касание.

## Поддержка телевизоров
- **Sony Bravia (включая модели 2013 года, такие как KDL-W805A, W650A, W900A и новее)**: через встроенный DLNA/UPnP Media Renderer. Телевизор автоматически переключается на прямой поток с телефона без необходимости открывать браузер или вводить коды.
- **Samsung Smart TV (Tizen / Orsay)**: прямое воспроизведение по Wi-Fi через DLNA DMR и WebRTC.
- **LG Smart TV (webOS / NetCast)**: прямое воспроизведение экрана и звука.
- **Android TV / Google TV / Xiaomi Mi TV / Philips / TCL**: мгновенное подключение с минимальной задержкой.

## Архитектура и технологии
1. **Захват экрана**: `MediaProjectionManager` и `VirtualDisplay` с аппаратным кодированием в реальном времени.
2. **Захват системного звука**: `AudioPlaybackCaptureConfiguration` (Android 10+ / API 29+) для прямого захвата внутреннего звука приложений, игр и видеоплееров без использования микрофона. Для Android 8–9 предусмотрен микрофонный тракт.
3. **Поиск телевизоров в сети Wi-Fi**: SSDP / UPnP M-SEARCH broadcast + mDNS discovery.
4. **Передача потока на ТВ**:
   - Встроенный легковесный HTTP-сервер потокового вещания на устройстве.
   - DLNA SOAP AVTransport контроллер для автозапуска трансляции на телевизорах 2013–2026 годов.
   - WebRTC Broadcaster для Smart TV с низкой задержкой.
5. **Интерфейс**: Jetpack Compose + Material 3 в ультраминималистичном стиле (список найденных ТВ + статус трансляции в одно нажатие).

## Сборка APK
1. Откройте директорию `android` в **Android Studio** (Hedgehog / Iguana / Jellyfish / Ladybug).
2. Выберите устройство или эмулятор и нажмите **Run** (или выполните команду `./gradlew assembleDebug` / `./gradlew assembleRelease`).
3. Готовый APK файл будет в папке `android/app/build/outputs/apk/`.
